# web-controller

Веб-пульт управления дроном для смартфона в горизонтальной ориентации. Два стика под большие пальцы и переключатель режима Angle/Acro. Каждый кадр анимации страница публикует состояние пульта в MQTT-брокер по WebSocket.

## Управление (Mode 2)

| Стик   | Ось            | Канал    | Возврат в центр |
|--------|----------------|----------|-----------------|
| Левый  | Вверх / вниз   | Throttle | Нет, стартует снизу |
| Левый  | Влево / вправо | Yaw      | Да              |
| Правый | Вверх / вниз   | Pitch    | Да              |
| Правый | Влево / вправо | Roll     | Да              |

Оси независимы (квадратный ход), вверх и вправо значение растёт.

## Отчёт

10 байт, little-endian, публикуется с частотой обновления экрана:

```
ReportId (u8, всегда 2) | Throttle | Yaw | Pitch | Roll (u16 каждый) | FlightMode (u8)
```

## Структура

```
public/                       статика, которую раздаёт nginx
  js/config.js                адрес брокера и топик
  js/protocol.js              кодирование 10-байтового отчёта
  js/controller-state.js      состояние пульта из событий стиков и режима
  js/report-publisher.js      подключение к брокеру и публикация каждый кадр
  js/stick.js                 стик: касание, ограничение хода, возврат в центр
  js/mode-toggle.js           переключатель Angle/Acro
  js/connection-indicator.js  индикатор связи с брокером
  js/fullscreen-toggle.js     полноэкранный режим
Dockerfile                    nginx со статикой
docker-compose.yml            публикация на порту 80
```
